# airtime-call-tracker-extension: правила работы

## Ветки и PR — обязательно
Правило владельца (2026-10-06), общее для всех репозиториев `grangegrange/*`:
1. Никогда не коммитить в `main`/`master` напрямую.
2. Работа — в топик-ветке от `develop` (`feat/…`, `fix/…`, `docs/…`), лучше в отдельном `git worktree`: живые каталоги сервисов стоят на `main`/`master`.
3. PR идёт в `develop`. Релиз `develop` → `main`/`master` — отдельный PR.

## Проверки
Зелёные тесты проекта (команды — в README) — условие merge; на каждый найденный баг — регрессионный тест.

## Данные и секреты
`.env`, `data/`, кэши, логи и секреты в git не попадают.

## Общий код
Что не зависит от предметной области проекта (outbox das-notify, бэкап SQLite, панель, чат, безопасный SQL), — в `grangegrange/watcher-kit` (`docs/ROADMAP.md`):
перед новым модулем посмотреть, нет ли его там или в соседних проектах.
